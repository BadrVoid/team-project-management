# Team Project Management System

A full-stack project management platform for college and university teams.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Axios

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven

### Infrastructure
- Docker
- Docker Compose

## Project Structure

- `frontend/` — React application
- `backend/` — Spring Boot application
- `docs/` — Project documentation
- `docker-compose.yml` — Local infrastructure
